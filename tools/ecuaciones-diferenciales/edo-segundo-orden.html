EDO de Segundo Orden

Solución gráfica de a·y″ + b·y′ + c·y = g(t)

Ecuación diferencial lineal de segundo orden con coeficientes constantes y valores iniciales y(0), y′(0). La solución se obtiene con la ecuación característica y se compara con la integración numérica (Runge–Kutta 4).

—

Solución y(t)

y(t) solución yh homogénea yp particular RK4 numérica recta tangente (pendiente y′)
t = 0

Plano de fase (y, y′)

Campo de direcciones del sistema y′ = v, v′ = (g(t) − b·v − c·y)/a.

Modelo masa–resorte

m = a, amortiguamiento = b, constante del resorte = c, fuerza externa = g(t).

Ejemplos: 2y'' - 3y' + y = 0, y'' + 4y = cos(2t), y'' + y' + 4y = 3sen(1.5t), y'' - y = 2e^(-t), y'' + 2y' + 5y = 10. Luego ajusta y(0) y y′(0) abajo.
