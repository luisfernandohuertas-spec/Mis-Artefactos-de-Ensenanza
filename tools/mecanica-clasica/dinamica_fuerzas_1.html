Dinámica de un Bloque

Un bloque descansa sobre una superficie horizontal con peso, normal y fricción. Arrastra con el mouse sobre el bloque para aplicarle hasta tres fuerzas horizontales, define su posición y velocidad iniciales, y luego reprodúcelo: el mismo bloque se desliza y deja su propio rastro de posiciones.

Configuración de fuerzas

Arrastra con el mouse desde el bloque hacia la izquierda o la derecha para crear una fuerza horizontal (máximo 3). Vuelve a arrastrar el extremo de una flecha para ajustarla.
